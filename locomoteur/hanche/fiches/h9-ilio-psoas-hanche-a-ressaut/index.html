Fiche H9

Hanche · ressaut interne ou externe · danseur

Ilio-psoas / hanche à ressaut

Épidémiologie

Ressaut indolore 5–10 % ; symptomatique jusqu'à 58 % des danseurs de ballet d'élite.270,271

Présentation clinique

Ressaut antérieur (interne) ou latéral (externe, le plus fréquent).272

Examen physique

Interne : ressaut de la flexion-abduction-rotation externe vers l'extension ; externe : test d'Ober ; performance non établie.273,274

Physiopathologie

Interne : le tendon du psoas claque quand l'iliaque médial se libère ; externe : bandelette ilio-tibiale sur le grand trochanter.275

Diagnostic différentiel

Lésion du labrum, corps libre, grand trochanter.276,277

Investigations

Échographie dynamique.275

Traitement

Physiothérapie ≥ 3 mois (19/30 améliorés) ; infiltration de la bourse (29/40 soulagés) ; libération arthroscopique : récidive 5,1 % contre 21,7 % (ouverte).272,274,278

Pronostic

Non documenté.
