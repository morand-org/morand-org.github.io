Fiche M3

Poulie a1 · ténosynovite sténosante · diabète

Doigt à ressaut

Épidémiologie

2–3 % ; diabète (25–42 % à vie dans le type 1) ; femmes de 50–60 ans ; pouce, majeur, annulaire.26,27,28

Présentation clinique

Accrochage, puis blocage douloureux.29

Examen physique

Nodule sensible à la poulie A1, ressaut à la fermeture du poing ; aucun test validé.17

Physiopathologie

Disproportion entre le tendon et la poulie A1 (tendinose, métaplasie fibrocartilagineuse).30,27

Diagnostic différentiel

Dupuytren, infection, arthrite, tendinite des extenseurs.17

Investigations

Clinique ; HbA1c si diabète possible.31

Traitement

Attelle ou infiltration, équivalentes jusqu'à 52 semaines ; infiltration : succès 57 %, récidive 22 %, échec chez 78 % des diabétiques insulinotraités ; libération : résolution 94 % contre 62 %.32,17,33

Pronostic

Résolution spontanée 20–29 % ; 20 % opérés en 3 ans après infiltration.26,28
