Fiche Co11

Coude · condyle latéral, col radial, épicondyle médial

Autres fractures du coude de l'enfant

Épidémiologie

Condyle latéral 10–20 % ; col radial 5–10 % (7–12 ans) ; épicondyle médial 10–20 % (10–12 ans, luxation associée 24–60 %).106,107,108,109

Présentation clinique

Chute sur la main ; avulsion en valgus pour l'épicondyle médial.110,106,111

Examen physique

Aucun signe validé ; condyle latéral manqué dans 60 % en première ligne ; nerf ulnaire atteint dans 10–16 % (épicondyle médial).107,112

Physiopathologie

Condyle latéral : fracture articulaire Salter-Harris IV déplacée par les extenseurs.113,114

Diagnostic différentiel

Fragment incarcéré (un quart des luxations), Monteggia.115,45

Investigations

Face, profil, oblique interne, clichés comparatifs.33

Traitement

Condyle latéral ≤ 2 mm : plâtre et contrôle (déplacement secondaire 8,5–26,8 %) ; col radial < 30° : plâtre ; épicondyle médial : chirurgie non supérieure (SCIENCE).113,116,117,109

Pronostic

Condyle latéral consolidé en 6,4 semaines ; épicondyle médial plâtré : pseudarthrose radiologique 68,6 % sans perte fonctionnelle.118,112
