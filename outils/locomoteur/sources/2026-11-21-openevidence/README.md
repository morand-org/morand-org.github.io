# Document OpenEvidence du 21 novembre 2026

Réponses d'OpenEvidence (assistant de recherche médicale qui cite ses références) obtenues par le clinicien et fournies
sous forme de document Word, pour toutes les régions. Chaque partie est conservée telle quelle, avec ses références ;
les numéros de références sont propres à chaque partie (« B81 » = référence 81 de la partie B).

| Partie | Contenu | Utilisé pour |
|---|---|---|
| [A](A-frequences.md) | Diagnostics les plus fréquents par région, top 20 tous âges (prévalence, incidence) | Liste des diagnostics, probabilités de départ |
| [B](B-tests-speciaux.md) | Tests spéciaux et grappes : Se, Sp, RV+, RV− | Poids des tests et des grappes |
| [C](C-populations.md) | Top 10 par région selon la population (enfant, adulte, sportif, sujet âgé) | Probabilités de départ selon l'âge et le sport |
| [D](D-examen-de-base.md) | Examen de base : inspection, posture, amplitudes, force, neuro, palpation, fonctionnel | Poids de l'examen |
| [E](E-anamnese.md) | Questions d'anamnèse : Se, Sp, RV ; drapeaux rouges | Poids de l'anamnèse, alertes |
| [F](F-conduites.md) | 268 fiches de conduite de première ligne et posologies, avec références | Conduite (sources) |
| [G](G-confirmer-exclure.md) | Pour chaque diagnostic : éléments pour confirmer, pour exclure, pièges | Choix des questions, infos « i » |
| [H](H-aide-memoire-quebec.md) | Aide-mémoire de première ligne (Québec) par région : investigation, traitement, suivi, référence | Conduite (texte), mesures générales |

Méthode déclarée par OpenEvidence : méta-analyses d'abord, puis études en première ligne ou en médecine du sport ;
« calc. » = RV calculé à partir de Se et Sp publiées (sans intervalle de confiance) ; « † » = valeur ou rang non vérifié
dans le texte source, ou conduite fondée sur les principes généraux. Dans l'outil, ces chiffres ont le statut
« vérifié » ; ceux marqués « † » restent « à vérifier ».

Ce qui n'est pas repris : les figures (droits des éditeurs) ; leur lien et leur légende restent dans le texte.
